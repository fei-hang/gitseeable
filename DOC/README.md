## 1. 启动应用

### 环境要求

- Node.js v20.19.3

### 启动步骤

```bash
# 安装依赖
npm install
cd client && npm install
cd ../server && npm install

# 启动开发服务（同时启动前端和后端）
cd ..
npm run dev
```

启动成功后，浏览器访问 **http://localhost:3000** 即可进入应用。

![目录选择](04-directory-select.png)

## 2. 选择 Git 仓库

### 选择已有路径

页面顶部会显示最近访问过的仓库路径，点击 **分析仓库** 按钮即可进入。

### 手动输入路径

1. 在输入框中输入 Git 仓库的完整路径
2. 点击 **确认** 按钮
3. 应用会自动检测该目录是否为 Git 仓库

### 浏览目录

点击页面底部的目录列表，可以逐级浏览文件系统，找到目标仓库后点击进入。

![目录选择](04-directory-select.png)

## 3. 提交历史

进入仓库分析页面后，默认显示 **提交历史** 标签页。

### 功能说明

- **提交列表**：按时间倒序显示所有提交，包含提交信息、作者、日期和提交哈希
- **分支图**：左侧以 ASCII 图形展示分支拓扑结构，不同分支使用不同颜色区分
- **分页控制**：
  - 每页显示数量：10 / 20 / 50 / 100 / 200 条
  - 点击 **上一页 / 下一页** 翻页
  - 支持输入页码跳转

### 查看提交详情

点击任意提交行，展开该提交的文件变更列表。再次点击某个文件，可查看该文件的详细 diff。

![主界面概览](01-main-overview.png)

## 4. 分支管理

### 查看分支

左侧面板列出所有分支：
- **本地分支**：当前仓库的本地分支列表
- **远程分支**：远程仓库的分支列表

当前所在分支高亮显示并带有选中标记。

### 分支操作

在分支上右键点击可弹出上下文菜单，支持以下操作：

| 操作 | 说明 |
|------|------|
| 切换 | 切换到该分支 |
| 创建 | 基于当前分支创建新分支 |
| 合并 | 将该分支合并到当前分支 |
| 变基 | 将当前分支变基到该分支 |
| 重命名 | 修改分支名称 |
| 删除 | 删除分支 |
| 推送 | 推送到远程仓库 |
| 拉取 | 从远程仓库拉取 |

### 分支筛选

双击左侧分支列表中的分支名，提交历史将仅显示该分支的提交。点击顶部分支标签可恢复显示所有分支。

## 5. 本地修改

点击 **本地修改** 标签页，查看工作区的变更状态。

![本地修改](02-local-changes.png)

### 功能说明

- **变更列表**：显示所有已修改、已暂存和未跟踪的文件
- **操作按钮**：
  - **暂存**：将文件添加到暂存区
  - **取消暂存**：将文件从暂存区移出
  - **还原**：撤销对文件的修改
- **文件对比**：点击文件可查看该文件的差异对比

### 提交本地变更

1. 暂存需要提交的文件
2. 在底部输入提交信息
3. 点击 **提交** 按钮

### 冲突解决

合并或变基操作如果产生冲突，应用会显示冲突文件列表，支持逐文件解决冲突。

## 配置说明

应用的状态（包括最近的仓库路径、主题偏好等）会自动保存到 `server/state.json` 文件中，重启应用后会自动恢复。

## 常见问题

### Q: 启动后页面无法访问？

确保服务端（端口 3001）和客户端（端口 3000）都已成功启动，检查终端是否有报错信息。

### Q: 仓库变更没有自动刷新？

应用通过 SSE（Server-Sent Events）实时监听文件变更，如果自动刷新失效，可以手动点击刷新按钮。

### Q: 如何切换 Node.js 版本？

```bash
nvm use 20.19.3
```
